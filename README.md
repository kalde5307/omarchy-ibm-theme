## 📘 Overview

omarchy-ibm-theme is an IBM and ThinkPad style theme for Omarchy. It gives your desktop a clean, old-school look that feels close to the classic IBM design. If you want your Omarchy setup to match that style, this theme keeps the look simple and easy to use.

This project fits well for users who want a darker, practical desktop with a strong retro feel. It is made for Omarchy and follows the theme format used by that system.

4. Sign out and sign back in.

If the theme looks incomplete:

1. Confirm that all theme files are present.
